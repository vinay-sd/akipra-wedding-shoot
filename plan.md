# Cinematic Indian Wedding Landing Page — AI Copilot Reference

## Project Goal

Create a modern, ultra-cinematic, emotionally immersive landing page for a premium Indian wedding cinematography and photography brand.

The website should:

- feel like a luxury wedding film
- emotionally guide users through the experience
- showcase cinematic storytelling skills
- convert visitors into inquiries/leads
- feel premium, modern, elegant, emotional, immersive
- work exceptionally well on mobile
- use stock cinematic wedding footage initially
- later replace all stock assets with actual client footage

This is NOT a traditional photography website.

This is:

> a cinematic digital experience designed to emotionally convert couples.

---

# Core Brand Positioning

DO NOT position as:

- wedding photographers
- videographers
- event coverage team

Position as:

> cinematic storytellers for Indian weddings.

---

# Design Philosophy

The website should feel inspired by:

- luxury fashion campaigns
- Netflix intros

- Bollywood emotional cinematography

- modern cinematic UI experiences

Avoid:

- generic photography templates

- colorful clutter
- traditional cards
- excessive text
- outdated wedding aesthetics
